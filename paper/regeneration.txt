How to regenerate every number in the paper
  "Conserved amount, negotiable placement.
   Prompting perturbs one architecture, an AI reviewer both"

Every number the paper prints is produced by a script in tools/gallery/, read
off the per-checkpoint CSVs shipped beside this file under anc/results/. No
number is hand-entered. This file maps each table, figure and inline figure to
the exact command that regenerates it, so a reader can recompute all of it and
check it against the paper. If a command's output ever disagrees with the paper,
the script is the authority, not the prose.

The run ids and the condition each maps to are in anc/results/README.


ENVIRONMENT

The scripts need Python with numpy. From the repository root, either run
./setup.sh once to build the .venv the commands below use, or install numpy into
any Python and call that interpreter in place of ./.venv/bin/python.

All bootstrap figures use a fixed seed of 0 and 20,000 resamples (10,000 in
bootstrap_ratio, overridable with --n-boot), resampling CHAINS not checkpoints.
Re-running reproduces the same numbers. "final phase" means the rows with
phase == Final, change requests 49-60, aggregated chain-first (each chain's mean
over its final-phase rows, then the mean over the ten chains, sample SD ddof=1).


ALL NUMBERS AT ONCE

  ./.venv/bin/python -m tools.gallery.paper_cells
  ./.venv/bin/python -m tools.gallery.bootstrap_ratio --latex --conditions both
  ./.venv/bin/python -m tools.gallery.floor_effect --conditions both
  ./.venv/bin/python -m tools.gallery.plasticity_dist --conditions both --out /tmp/pd
